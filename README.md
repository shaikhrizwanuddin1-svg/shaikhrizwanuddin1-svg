## 🚀 Featured Project

### 🌱 AgriSpray AI — AI-Powered Targeted Crop Spraying

**AgriSpray AI** is a project by **Visionary Devs** designed to help farmers reduce unnecessary pesticide usage by identifying crop/leaf conditions and recommending targeted spraying.

**Core idea:**

`Scan Leaf → Detect Condition → Confidence → Severity → Spray Decision → Cost Saving`

**Key features**
- 📷 Plant/leaf scanning
- 🧠 AI-based disease/condition detection
- 📊 Confidence and severity analysis
- 🌾 Targeted spraying recommendation
- 💰 Estimated pesticide/cost savings
- 🌦️ Weather-aware recommendations
- 🗣️ English / Hindi / Marathi farmer-friendly interface
- 📈 Scan history and analytics
- 📡 Simulated IoT integration
- 🔐 OTP-based authentication
- 🌙 Dark / light mode
- 📱 Responsive UI

**Tech:** React, TypeScript, Vite, Tailwind CSS, Framer Motion, Recharts, Node.js, Express, PostgreSQL, Twilio and weather APIs.

🏆 **HACKSPECTRA 2.0 — MGM's College of Engineering, Nanded**  
Presented the project through multiple evaluation rounds and reached the later stage of the hackathon.
